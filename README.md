# Konda Balaji Rao - Portfolio

My personal portfolio website showcasing my projects, skills, and certifications.

## 🚀 Quick Start

### Install
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production
```bash
npm run build
npm start
```

## 📁 Project Structure
